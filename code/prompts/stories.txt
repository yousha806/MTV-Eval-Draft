System Prompt
 You are an expert multimodal evaluator specializing in cultural reasoning and narrative visual understanding. Evaluate whether an adapted story image remains faithful to the story while being culturally appropriate.
User Prompt
 You are given:
Source story image (illustration/comic panel/page)
Adapted image (system output)
Target culture description
Story text or scene description

Target culture: {target_culture_text}
Story text / scene description: {story_text}

Evaluate the images using the criteria below. Score each criterion from 1 (very poor) to 5 (excellent) and give brief reasoning (1–3 sentences) per criterion. Give scores such that for each criterion, a score of 4 and 5 would indicate overall success and a score of 1, 2, or 3 would indicate failure. 

A. Source Image Cultural Appropriateness (1–5)
 Rate the source image for how culturally appropriate it already is for the target culture. This helps measure the change in cultural appropriateness due to adaptation.
B. Adapted Image Cultural Appropriateness (1–5)
 Does the adapted image plausibly reflect the target culture in visual elements and setting?
C. Semantic Preservation — Stories (1–5)
 Is the adapted image coherent with the story text/scene description and faithful to the original meaning?
D. Visual & Structural Coherence (1–5)
 Is the image visually coherent and structurally consistent (e.g., panel structure, composition, character continuity)?

After scoring A/B/C/D, provide an Overall Success Score (1–5) that reflects overall task success. The task will be considered successful if: a) the adapted image preserves the semantic category of the original image (i.e., if the score for "C_semantic_preservation" is 4 or 5); and b) if the score for the adapted image's cultural appropriateness is greater than the score for the source image's cultural appropriateness (i.e. if the score for "B_adapted_cultural_appropriateness" is greater than the score for "A_source_cultural_appropriateness"). If the model fails to fulfil both of these criteria, assign a score of 0 for overall success. A score between 1-5 would be used to assess the degree of success. Briefly justify the overall score (1–3 sentences).
Return JSON only in the exact format:
